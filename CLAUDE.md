# CLAUDE.md

The instructions for working in this repo live in **[AGENTS.md](./AGENTS.md)**. Read it in full before touching any file.

Short version, so nothing gets missed if only this file loads:

- Route through `stack/INDEX.md` → `stack/CONTEXT.md` → only the sections the task needs. Never read the whole stack.
- **Never invent a number.** No source means `[TBD — what's needed, from where]`.
- Default every fact you extract to `[NEEDS VERIFICATION]`. Only the founder promotes to `[SOURCE OF TRUTH]`.
- Cite the origin of every fact you write: `(src: file, page/date)`.
- Update `updated:`, `status:` and `summary:` in front matter whenever you edit a file.
- Respect `sensitivity:` — carve shareable outputs, never export `restricted`.
- Never delete a file or a past recap without asking.
- No emoji. No marketing language. The founder's words, not better ones.

The full reasoning, the tag table, the sensitivity rules and the failure mode to avoid are in [AGENTS.md](./AGENTS.md).
